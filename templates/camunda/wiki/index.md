# Camunda Template

This repository documents Camunda projects as a semantic Wiki CLI corpus.

Use it to track:

- BPMN processes and owners
- DMN decisions and review cadence
- user tasks, forms, connectors, and job workers
- SLAs, KPIs, and system integrations
- rendered governance dashboards

Start with [Loan Approval Process](Loan_Approval_Process.md) and [Camunda Governance Dashboard](Camunda_Governance_Dashboard.md).
